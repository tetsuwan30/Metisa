# Metisa

Metisa は、共同作業のための Web アプリケーションです。
情報を整理・共有し、チームで利用するためのワークスペースを目指しています。

## アプリケーション

### Wiki

Google アカウント認証に対応した、階層型の Wiki アプリケーションです。
WYSIWYG エディタによるページ編集、ページの階層管理、更新履歴・差分比較などの機能を備えています。

主な機能：

- Google アカウント認証とメールアドレスによるアクセス制限
- ページの作成・編集・削除、親子関係による階層管理
- WYSIWYG エディタ、表・画像・リンクの挿入
- 目次、子ページ一覧、キーワードによるページ一覧の埋め込み
- Draft / In review / Approved のステータス管理
- 更新履歴、差分比較、過去バージョンの読み込み
- PC・スマートフォン対応

詳しくは [Wiki の機能一覧](docs/wiki/features.md) を参照してください。

## 動作環境・技術

| 項目 | 使用技術 |
|---|---|
| バックエンド | Ruby 2.6 |
| 実行方式 | CGI |
| フロントエンド | HTML / CSS / JavaScript |
| 認証 | Google OAuth 2.0 / OpenID Connect |
| データ保存 | ファイルベース |
| 設定ファイル | JSON |
| Ruby ライブラリ | Ruby 標準ライブラリ |

データベースや Rails などの Web アプリケーションフレームワークは使用していません。
Ruby CGI が利用できるレンタルサーバーでの動作を想定しています。
