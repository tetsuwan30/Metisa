# セキュリティ

現在の実装には、次の対策が含まれています。

- Google アカウントによる認証
- 許可メールアドレスによるアクセス制限
- HMAC-SHA256 によるセッション署名
- Secure / HttpOnly 属性付き Cookie
- OAuth の state パラメータ検証
- POST リクエストの Origin 検証
- 保存時の HTML サニタイズ
- 画像データの形式検証
- 画像アップロードサイズの制限
- 保存ファイルへのアクセス権限設定
- `.htaccess` によるデータディレクトリへの直接アクセス制限

## 注意事項

HTML サニタイズは独自実装の簡易的なものです。
公開環境や重要な情報を扱う環境で運用する場合は、セキュリティレビューを行い、必要に応じて専用ライブラリの導入などを検討してください。

また、`config.json` に含まれる `google_client_secret` や `session_secret` などの秘密情報を、公開リポジトリに登録しないでください。
