# Ticket の機能

Metisa Ticket は、プロジェクト単位で作業をチケットとして管理する Jira 風のチケット管理アプリケーションです。

## プロジェクト管理

- プロジェクトの作成・編集
- プロジェクトキー、名称、説明の管理
- プロジェクトごとのチケット採番
- プロジェクト別の未完了件数・総チケット数の表示
- プロジェクトの切り替えと全プロジェクト表示

プロジェクトキーは、英大文字で始まる2〜10文字の英数字です（例：`WEB`）。
チケット番号はプロジェクトキーと連番を組み合わせて生成されます（例：`WEB-1`）。

## チケット管理

- チケットの作成・編集・削除
- タイトルと説明の設定
- チケット種別、ステータス、優先度の設定
- 担当者の割り当て
- ラベルの設定
- 親チケットの設定
- 報告者、作成日時、更新日時の記録
- チケット ID による個別ページへのアクセス
- チケット URL のコピー

## チケット種別

| 種別 | 値 |
|---|---|
| タスク | `task` |
| バグ | `bug` |
| ストーリー | `story` |
| エピック | `epic` |

## ステータス

| ステータス | 値 |
|---|---|
| 未着手 | `todo` |
| 進行中 | `doing` |
| レビュー | `review` |
| 完了 | `done` |

## 優先度

| 優先度 | 値 |
|---|---|
| 最高 | `highest` |
| 高 | `high` |
| 中 | `medium` |
| 低 | `low` |
| 最低 | `lowest` |

## ボード表示・一覧表示

- ステータスごとにチケットを並べるボード表示
- チケットを表形式で表示する一覧表示
- ボード上のカードをドラッグ＆ドロップしてステータスを変更
- チケット種別、優先度、担当者の視覚的な表示
- プロジェクト内のチケット件数表示

## 検索・フィルター

- チケット ID、タイトル、ラベルによるキーワード検索
- 担当者による絞り込み
  - 全員
  - 自分
  - 未割当
  - 個別ユーザー
- チケット種別による絞り込み
- 優先度による絞り込み
- プロジェクトによる絞り込み

## 親子チケット

- チケットに親チケットを設定
- 親チケットの下に子チケットを階層表示
- 一覧サイドバーで階層を展開・折りたたみ
- 詳細画面で親チケットへのパンくずを表示
- 詳細画面から子チケットを確認
- 子孫チケットを親に指定する循環関係を防止
- 親チケットを削除すると、子チケットはひとつ上の階層へ繰り上げ

親チケットと子チケットは同じプロジェクト内に限られます。

## コメント

- チケットにコメントを追加
- コメント投稿者と投稿日時を記録
- コメント本文中の URL をリンクとして表示
- 既存チケット ID（例：`WEB-12`）をチケットへのリンクとして表示

## 更新履歴

- チケット作成時に作成履歴を記録
- 項目の変更履歴を記録
- 変更したユーザーと日時を記録
- タイトル、種別、ステータス、優先度、担当者、ラベル、親チケットなどの変更内容を表示
- 説明の変更は、内容そのものではなく更新された事実を記録
- 1チケットあたり最大200件の履歴を保持

更新履歴は参照用です。現行実装では、履歴から過去のチケット内容を復元する機能はありません。

## 削除

- 削除したチケットの JSON ファイルを `data/trash/` へ移動
- 子チケットは削除したチケットの親階層へ繰り上げ
- 削除したチケットを通常の一覧から除外

## 入力上限

- チケットタイトル：200文字
- プロジェクト名：100文字
- プロジェクト説明：300文字
- 説明・コメント：各200,000バイト
- ラベル：最大20個、1ラベル30文字

## 画面・操作性

- PC・スマートフォンのブラウザに対応した画面
- チケット一覧サイドバーの表示・非表示
- ボード表示と一覧表示の切り替え
- チケット詳細の閲覧・編集
- 未保存の変更がある場合の画面移動確認
- チケット URL を使った直接アクセス
