# Wiki の機能

Metisa Wiki は、Google アカウントでログインして利用する階層型の Wiki アプリケーションです。

## 認証

- Google OAuth 2.0 / OpenID Connect によるログイン
- 設定ファイルで許可したメールアドレスのみアクセス可能
- 署名付きセッショントークンによるログイン状態の管理
- ログアウト

## ページ管理

- ページの新規作成・編集・削除
- ページ ID の自動生成
- 親ページ・子ページによる階層管理
- ページの親階層の変更
- サイドバーでのページツリー表示、展開・折りたたみ
- タイトルによるページ検索
- パンくずリストによる階層表示
- ページごとのリンク（パーマリンク）
- ページリンクのコピー

## WYSIWYG エディタ

- 見出し（H1 / H2 / H3）
- 太字、斜体、下線、取り消し線
- 箇条書き、番号付きリスト
- 引用、コードブロック
- URL リンク、Wiki 内ページへのリンク、Wikipedia へのリンク
- 水平罫線、字下げ
- 表の挿入・行列の追加・削除
- 画像のアップロードと挿入
- 画像の貼り付け、ドラッグ＆ドロップによる挿入
- 書式のクリア、元に戻す、やり直す

## ページ内の埋め込み機能

ページ本文に、表示時に内容が生成される部品を挿入できます。

- **目次**：ページ内の見出しから自動生成（H1、H1・H2、H1・H2・H3）
- **子ページ一覧**：現在のページ直下にある子ページを表示
- **子孫ページ一覧**：下位階層のページをまとめて表示
- **キーワード一覧**：ページタイトルに指定したキーワードを含むページを表示
  - 複数キーワードは AND 条件で検索

## ページのステータス

| ステータス | 意味 |
|---|---|
| Draft | 下書き |
| In review | レビュー中 |
| Approved | 承認済み |
| ステータス無し | ステータス未設定 |

ステータスはページ一覧にも表示されます。

## 更新履歴・差分比較

- ページ本文またはタイトルが変更されたときに履歴を保存
- 更新者のメールアドレスと更新日時を記録
- 過去のバージョンの内容を表示
- 過去のバージョンと現在の内容の差分を表示
- 過去のバージョンを編集用に読み込み
- 1ページあたり最大100件の履歴を保持
- 内容とタイトルに変更がない場合は履歴を追加しない

## ページの削除

- 削除したページはデータディレクトリ内のゴミ箱領域へ移動
- ページの更新履歴もあわせて移動
- 削除したページの子ページは、削除したページの親階層へ移動

## 画像管理

- PNG / JPEG / GIF / WebP に対応
- 画像ファイルの形式をデータ内容から判定
- 画像アップロードの上限は 8 MB
- 画像はログイン済みユーザーに対して CGI 経由で配信

## 画面・操作性

- PC・スマートフォンのブラウザに対応
- ページ一覧サイドバーの表示・非表示
- 編集モードと閲覧モード
- 保存、保存して閲覧、編集内容の破棄
- Ctrl+S による保存
